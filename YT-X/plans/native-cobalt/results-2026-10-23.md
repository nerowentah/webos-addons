# Native Cobalt — device results, 2026-10-23

TV: LG 65QNED86 (webOS 25, firmware 33.31.75). Runtime: RF1705 2.0.6 prebuilt
(Cobalt 23.lts.6, Starboard 13), installed as `youtube.leanback.v4`. One TV is
one data point.

## Findings

| Topic                      | Result                                                                                                                                                                                                                                                                          |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Own app id                 | `com.ytx.native` plays until Cobalt registers its media luna service, then aborts with `LSRegisterPubPriv FAILED`. The same package as `youtube.leanback.v4` runs. Treat the stock id as required.                                                                              |
| Directory permissions      | After a TV reboot the app directory is 775 root; Cobalt aborts (SIGILL) when its storage save fails. A fresh install (`ares-install -r` then install) creates it 777. A reinstall also drops stored sessions.                                                                   |
| Executable bit             | The IPK needs `cobalt` mode 755 inside the tar; `chmod` is not possible as the ssh user.                                                                                                                                                                                        |
| Rapid relaunch             | Close plus launch within a few seconds makes Cobalt abort at startup (`LSRegisterPubPriv`). Wait for a full exit (about a minute) before relaunching.                                                                                                                           |
| Guest Home                 | Signed-out Home is a sign-in prompt with no tiles; Music and Search have content. A watch page plays in guest mode at 1920 px.                                                                                                                                                  |
| Bundle in the preload      | The full bundle never installs its hooks there: its top-level `await` modules wait on YouTube objects and `document.documentElement` is null at that point, so the entry stays pending with no error. `JSON.parse` stayed native.                                               |
| Two-phase injection        | `native-early` (response hooks only) in `adblockPreload.js` and the full bundle as `adblockMain.js`. `JSON.parse` is wrapped, a synthetic payload loses `adPlacements`/`adSlots`, and the config of both bundles stays in sync.                                                 |
| Styles                     | Cobalt ignores text set on a `<style>` already in the document (0 rules). style-loader inserts first and fills second, so the insert hook now appends after a microtask. With that, the badge is `position: fixed`, `z-index: 1100`.                                            |
| Missing DOM APIs           | `Element.remove` and `HTMLElement.click` do not exist; `src/platform/cobalt-polyfills.ts` fills them.                                                                                                                                                                           |
| Device name                | The placeholder tail reported `DESKTOP`. Launching through a wrapper with `--user_agent_client_hints` gives `SystemIntegratorName_TV_O18_0/33.31.75 (LG, 65QNED86ASA.ATSFLJD)`. `model_year=2025` or `connection_type=Wireless` crashed it at startup in one run; not isolated. |
| Panel                      | The badge opens the YT-X panel; Back closes it.                                                                                                                                                                                                                                 |
| Session across file update | Replacing `adblockPreload.js`, `adblockMain.js` and the launcher in place kept the signed-in identity (reinstall does not).                                                                                                                                                     |

## Not done

- Account page "Your devices" check needs a sign-in on the TV by the user.
- Cobalt CSP violation capture was not recorded; the style problem turned out to be the insert order, not CSP.
- Ad filtering was proven on a synthetic payload, not on a live ad response.
- Magic Remote pointer and wheel, SponsorBlock (off by design on Cobalt), cast.

## Addendum, later the same day

| Topic              | Result                                                                                                                                                                                                                                                                                                                                   |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Launcher script    | Replacing `cobalt` with a shell wrapper (used for the `--user_agent_client_hints` experiment and log capture) is unsafe: RF1705 issue #74 reports that the Luna (LS2) permissions bind to that exact binary, so hardware video and the settings screen break. The app then closed during video on this TV. `cobalt` stays the stock ELF. |
| Logging            | The binary writes `/tmp/cobalt-starterless.log` itself. A log left by an older app uid cannot be appended by the current uid, so crashes were silent until `/tmp` was cleared by a reboot.                                                                                                                                               |
| Cobalt CSS and DOM | No `display: grid`, `:checked`, `:focus-within`, `:first-child`, `var()`, 8-digit hex, `Element.closest`, `Element.remove`, `HTMLInputElement` global, or checkbox activation. The 3-column sections now use wrapping flexbox with percentage cells.                                                                                     |
| Setup tool         | `tools/native.ts` packages the RF1705 runtime with the YT-X scripts, keeps the stock ELF, and cleans earlier sessions on setup (running app, `com.ytx.native`, launcher scripts, scratch files). `update` swaps the two scripts without dropping the session.                                                                            |
| Device identity    | `--device-strings` patches the stock binary's default platform strings in place (same length, exactly-one-match check) instead of using a wrapper. Not yet verified on the TV.                                                                                                                                                           |

## Phone cast list names (2026-10-24)

- Destinations: the system Cast receiver (`[LG] webOS TV QNED86ASA`, from `:8008/setup/eureka_info`) and the app's own
  YouTube lounge screen. The native appinfo has no `dialAppName`; `/apps/YouTube` on the DIAL server is 404.
- The lounge bind/test URLs carry `deviceInfo` (`brand`, `model`, ...); the phone prints brand + model. The early hook
  (`src/native/identity.ts`) sends brand `[YT-X]` and model `webOS TV QNED86ASA`; `window.__ytxLounge` holds the last
  values seen (xhr transport on this build).
- Google keeps a screen record per registration. Every `setup` (reinstall, new sign-in) leaves an old record with the
  old name; a TV reboot does not clear it. Remove old TVs on the phone (Settings > Watch on TV) and prefer
  `native.ts update` over `setup`.
- "Block Cast Wake" does nothing on native; the box is greyed out there.
