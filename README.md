# webOS Add-ons

Ad-free YouTube client for LG webOS TVs, and related webOS tooling.

## Apps

| App            | Description                                         |
| -------------- | --------------------------------------------------- |
| [YT-X](./YT-X) | Ad-free YouTube client for LG webOS TVs (webOS 6+). |

Each app lives in its own directory with its own `package.json`, build, and CI
expectations. See the app's README for build, install, and usage instructions.
